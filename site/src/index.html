macOS—

macOS 27 и новее

Скачать .dmg ↓

Последняя версия на GitHub

Как установить
  1. Открой .dmg и перетащи Hako в «Программы».
  2. Сборка не нотаризована Apple, поэтому при первом запуске macOS может её заблокировать. Открой «Системные настройки → Конфиденциальность и безопасность» и нажми «Всё равно открыть».
  3. Или сними карантин в Терминале: xattr -dr com.apple.quarantine /Applications/Hako.app
Windows—

Windows 10 (1809) и новее · x64 и ARM64

Скачать x64 ↓ ARM64 ↓

Последняя версия на GitHub

Как установить
  1. Hako подписан самоподписанным сертификатом. Скачай Hako.cer, открой его и нажми «Установить сертификат».
  2. Выбери «Локальный компьютер» → «Поместить все сертификаты в следующее хранилище» → «Доверенные лица» (Trusted People).
  3. Или в PowerShell от имени администратора: Import-Certificate -FilePath .\Hako.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
  4. Открой .msix для своей архитектуры и нажми «Установить».

Все версии и история изменений — на странице GitHub Releases.

ЕСТЬ ВОПРОСЫ?

Ответы
без квестов.

?✿
Сколько стоит Hako? +

Нисколько. Hako бесплатный, исходный код открыт на GitHub под лицензией MIT.

Hako — официальный лаунчер Minecraft? +

Нет. Hako — независимый проект и не связан с Mojang Studios или Microsoft. Игра скачивается с официальных серверов Mojang.

Нужна ли лицензия Minecraft? +

Для игры на серверах с проверкой аккаунта нужен вход через Microsoft с купленной Minecraft: Java Edition. Без входа доступен offline-режим.

macOS пишет, что приложение нельзя открыть +

Сборки Hako не нотаризованы Apple. Открой «Системные настройки → Конфиденциальность и безопасность» и нажми «Всё равно открыть» — это нужно сделать один раз. Обновления, установленные самим лаунчером, открываются без предупреждения.

Windows не даёт установить MSIX +

Сначала установи сертификат Hako.cer из того же релиза в хранилище «Локальный компьютер → Доверенные лица», затем повтори установку. Ошибка 0x800B010A означает, что сертификат не установлен или попал не в то хранилище.

Как обновлять Hako? +

Лаунчер сам проверяет новые стабильные версии и предлагает обновиться в настройках. Скачивать новую версию с сайта вручную не нужно.

Будет ли поддержка CurseForge? +

Да, она в планах. Сейчас моды, ресурспаки и датапаки устанавливаются из Modrinth или из локальных файлов.
