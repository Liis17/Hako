# Landing

Parent: [[Index]]

## Назначение

Статический лендинг `hako.liis17.com` в `site/`: описание возможностей и загрузка стабильных релизов. Без зависимостей и сборщиков; `site/build.sh` копирует `site/src/` в `site/dist/` (в git не хранится) и добавляет хеш содержимого к именам CSS и JS. `dist/` раздаётся nginx по `site/nginx/hako.liis17.com.conf`.

## Связи

- Ссылки на загрузку строятся в браузере (`site/src/script.js`) из GitHub API: максимальные стабильные теги `macos-vX.Y.Z` и `windows-vX.Y.Z` и имена ассетов из `.github/workflows/release.yml` (`Hako-X.Y.Z-macos.dmg`, `Hako-X.Y.Z-windows-{x64,arm64}.msix`, `Hako.cer`). При переименовании ассетов обновляй сайт. Обновления клиентов — [[App/Updates]].
- Без ответа API кнопки ведут на GitHub Releases.
- Последняя версия Minecraft для иллюстраций берётся из манифеста Mojang.
- Внешние адреса `fetch` перечислены в `connect-src` CSP конфига nginx; новый источник нужно добавить туда.
- Иконка сайта генерируется из `haku.png`.

## Ограничения

- Тексты возможностей и статус (готово / в планах) поддерживаются вручную и не проверяются CI.
- Изменения `site/` не поднимают версии платформ и не участвуют в релизах.
