# Hako — База знаний

Hako — нативный macOS-лаунчер Minecraft на SwiftUI и SwiftData (Xcode 27, macOS 27.0+)
с авторизацией через Microsoft и интеграцией Modrinth и CurseForge.
Эта функциональность пока не реализована: код соответствует стандартному шаблону
Xcode App с SwiftData — одно окно со списком записей с меткой времени.
