# Hako — База знаний

Hako — нативный лаунчер Minecraft для macOS на SwiftUI и SwiftData (Xcode 27, macOS 27.0+)
с авторизацией через Microsoft и интеграцией Modrinth и CurseForge.
Сейчас реализованы приветствие, вход в Microsoft по коду, главная страница с вкладками и настройками
и выход, создание и фоновая установка ванильных сборок с независимой Java, профили и локальные текстурпаки.
Игра запускается с Minecraft-сессией либо явным offline-mode; лаунчер доступен без аккаунта.
Время игры учитывается отдельно для аккаунта и каждой сборки, сохраняется после удаления сборок
и продолжает измеряться при закрытом Hako. Гостевая статистика переносится при входе.
Создаются Vanilla- и Fabric-сборки; Fabric API автоматически устанавливается из официального проекта Modrinth.
Каталог готовых модпаков Modrinth создаёт Fabric/Vanilla-сборки из `.mrpack`. Каталог контента ставит в сборку моды и ресурспаки, а в выбранный мир — датапаки с обязательными зависимостями; CurseForge пока не реализован.
Ресурспаки и датапаки сохраняют источник и версию Modrinth и обновляются по одному или всем разделом/миром;
датапаки также устанавливаются локально из ZIP/папок через выбор файла и перетаскивание.
Сборку и её миры можно удалить, дублировать, сохранить в резервную копию и восстановить из файла Finder на macOS.
Скриншоты сборки показываются сеткой, перетаскиваются в Finder копией, открываются в Quick Look и удаляются в корзину.
Интерфейс на русском и английском; язык выбирается на приветствии и в настройках и меняется без перезапуска.
CI публикует независимые стабильные релизы macOS и Windows при повышении версии соответствующей платформы. macOS-клиент проверяет и устанавливает обновления из стабильных macOS-релизов GitHub; переход прежних клиентов `nightly` выполняется вручную.
Windows-клиент (`windows/`, WinUI 3, .NET 8) поддерживает Vanilla/Fabric, запуск, раздел «Хранилище» с дисковым объёмом и разбивкой размера сборок по категориям, локальные моды и ресурспаки,
миры и датапаки, каталог Modrinth, готовые сборки `.mrpack`, скриншоты, дублирование сборок, резервные копии
`.hakobackup`/`.hakoworld`; игровое время сохраняется по аккаунту/гостю и сборке, продолжает учитываться после закрытия
лаунчера, а гостевые счётчики переносятся при входе. Вход Hako через Telegram независим от Microsoft и сохраняется отдельно; Microsoft по-прежнему даёт Minecraft-сессию. Восстановление этих архивов поддерживается на обеих платформах.
Автообновление Windows проверяет стабильные релизы GitHub и по кнопке обновляет MSIX с перезапуском; установка ожидает завершения игр и файловых операций. CurseForge ещё не реализован.
Статус описан в [[UI/Launcher#Windows-клиент]] и заметках по доменам.
