# Launcher

Parent: [[Index]]

## Назначение

Главная страница лаунчера для пользователя с аккаунтом или гостя: узкий стеклянный рейл вкладок слева
и содержимое выбранной вкладки справа. Общий сервис обновляет Minecraft-сессию при наличии аккаунта.
Показывается [[UI/ContentView]] после входа либо выбора «Продолжить без аккаунта».

## Рейл

`LauncherRail` — колонка 72 pt, `glassEffect` со скруглением 26, отступ 12 pt от краёв окна;
сверху вниз:

1. «Сборки» (`shippingbox.fill`) → `.instances`.
2. Разделитель, прокручиваемый список иконок `GameInstance` и кнопка «+» → форма новой сборки.
3. Внизу «Настройки» (`gearshape.fill`) → `.settings` и аватар аккаунта (`AccountAvatar` 40 pt)
   либо иконка гостя (`person.crop.circle`) → `.profile`.

Выбранная иконка — белая на `sakuraDeep`, при наведении — лёгкая подсветка; у выбранного аватара
обводка `sakuraDeep`. Иконки сборок открывают `.instance(UUID)`; настройки и аккаунт закреплены снизу. Подписи вкладок — в подсказках (`.help`) и `accessibilityLabel`.
Системное кольцо фокуса отключено (`.focusEffectDisabled()`). Смена вкладки — `.id(tab)` +
`.transition(.blurReplace)` с анимацией `.smooth`.

## Вкладки

| Вкладка | Подпись | Содержимое |
|---------|---------|------------|
| `InstancesView` | パック | «Сборки», центрированный блок создания первой сборки либо адаптивная сетка карточек |
| `InstanceProfileView` | — | Профиль выбранной сборки: установка, моды, текстурпаки, настройки и миры |
| `SettingsView` | 設定 | Разделы «Основные», «Игра», «Хранилище», «О приложении» |
| `ProfileView` | プロフィール | «Профиль»: строки Xbox и Java Edition, общее время Minecraft, кнопка «Выйти», 3D-скин и активный плащ справа |
| `GuestProfileView` | プロフィール | Гостевое время, пояснение о переносе при входе и кнопка Microsoft-входа |

`ProfileView(account:minecraftStatus:)` — две колонки: слева заголовок, две стеклянные строки
(ширина 400–600 pt), общее время и выход; справа [[UI/MinecraftSkin|3D-скин, а при наличии — активный плащ]] на прозрачном фоне.
Колонки разделены 32 pt, область модели — от 240 pt, компоновка поддерживает минимум окна 960×540. Левая колонка прокручивается, чтобы статистика
и выход оставались доступны при небольшой высоте.

Строки аккаунтов:

- Xbox: круглый `XboxAvatar`, gamertag, email (если есть), метка «Xbox».
- Java Edition: `MinecraftHead` и ник Minecraft; если Minecraft не подключён — иконка-заглушка,
  «Minecraft не подключён» и текст по `MinecraftStatus` (`idle` — недоступен для аккаунта,
  `connecting` — «Подключаем Minecraft…», `failed` — сообщение ошибки).
  `MinecraftStatus` определён в `Auth/MinecraftSessionCoordinator.swift`; сохранённый ник сам по себе не подтверждает сессию.

`PlaytimeSummaryView(xuid:)` показывает «Время в Minecraft» через общий `PlaytimeCoordinator`.
Статистика привязана к XUID; `nil` выбирает гостя. `PlaytimeFormatter.string(_:)` используется также
для сборок: `0 мин`, `меньше минуты`, целые минуты либо часы и минуты, без перехода к дням.
Значения обновляются при чтении игровых журналов каждые 10 секунд, без повторного открытия страницы.
Ошибка записи отображается в строке статистики; игра продолжается. При Microsoft-входе накопленное
гостевое время и работающие гостевые сессии переходят аккаунту ([[Data/Persistence]]).

3D-превью использует UUID, URL и вариант скина из `Account`. До загрузки и при ошибке
показывает классического Стива; реальные статус подключения и аватары строк остаются источником
информации об аккаунтах. Детали формата, кэша и анимации — [[UI/MinecraftSkin]].

«Выйти» сначала показывает подтверждение (`alert` «Выйти из аккаунта?», «Выйти» / «Отмена»),
защита от случайного выхода. После подтверждения: `TokenKeychain.delete(for: xuid)`, `modelContext.delete(account)`, `modelContext.save()`;
[[UI/ContentView]] возвращает приветствие. Сборки и их установка не зависят от `Account` и сохраняются.

## Создание сборки

Блок «Создайте первую сборку», кнопка над сеткой и плюс рейла открывают один `InstanceCreationView`.
Порядок полей: иконка/имя → каталог Minecraft → Vanilla/Fabric → версия Loader → раскрываемые параметры запуска.
Для Fabric форма предварительно проверяет официальный Fabric API из Modrinth в кэше и показывает только Loader,
удовлетворяющие его требованиям. Рекомендуемый Loader выбран по Meta `stable`; API закрепляется при сохранении.
Отсутствующий API, несоответствие Java или ошибка проверки блокируют сохранение Fabric; запрос можно повторить.
Смена Minecraft/Loader отменяет старые задачи, а ключи проверенного выбора не допускают сохранения устаревшего результата.
Строка «Дополнительные настройки» переключает раскрытие целиком, включая щелчок по тексту и свободной части строки.
Каталог Mojang поддерживает поиск и фильтры релизов, снапшотов, исторических версий и всех версий;
изначально выбран последний релиз. До сохранения `MojangClient.prepare` проверяет нативную совместимость
([[Minecraft/Installation]]). Несовместимость блокирует сохранение; при сетевом сбое доступен повтор.

Имя проверяется через `InstanceStore.validateName`; правила и коллизии — в [[Data/Persistence]].
Иконки — шесть встроенных SF Symbols либо PNG/JPEG. Пользовательская картинка нормализуется в квадратный
PNG 256×256 в памяти; до сохранения папка сборки не создаётся.
`InstanceParametersEditor` редактирует `InstanceDraft`: две взаимоисключающие галочки задают
`LaunchArgumentSource`; обе выключены — `custom`, новые сборки — `mojang`.
Глобальный режим показывает текущие аргументы и память через `@AppStorage`, блокирует их редактирование;
пустые аргументы и пользовательский путь Java сопровождаются предупреждениями.
Заблокированные поля сохраняют видимые значения: Java в глобальном режиме показывает аргументы
с применённым пределом heap, Mojang — обязательные и рекомендуемые аргументы выбранной версии.
`MinecraftLaunchPlan.argumentTemplates` общий с подготовкой запуска: учитывает OS/arch/features,
память и окно; пути и значения аккаунта показаны как `${…}`, без чтения токенов.
Создание передаёт проверенный manifest; профиль читает локальный JSON с проверкой SHA-1
или получает его через `MojangClient.manifest`, если установка ещё не сохранила файл.
Ошибка чтения сопровождается повтором загрузки параметров.
Переключение режима сохраняет собственный черновик. Окно редактируется независимо;
размеры — положительные целые числа, полноэкранный режим отключает поля размеров.
`JavaMemorySlider` общий для лаунчера и сборки: в глобальном режиме сборки он наследуется и отключён;
выбор более 70% памяти сопровождается предупреждением. Подпись отличает Java heap от общего расхода процесса.
Offline-mode показывает поле ника и предупреждение о недоступности части серверов;
невалидный ник блокирует сохранение. Настройки профиля сохраняются явно.

Sheet не закрывается кликом снаружи (`interactiveDismissDisabled`). Escape и Cmd+W перехватывает
локальный `CreationDismissGuard`: они, как и «Отмена», открывают подтверждение.
Подтверждённая отмена удаляет только черновик. После успешного `InstanceStore.create` форма закрывается,
выбирается вкладка сборок и запускается общая очередь. Ошибка сохранения остаётся в форме.

Карточка (адаптивная сетка, минимальная ширина 320 pt) показывает иконку, имя, Minecraft, выбранный Loader и прогресс установки.
Кнопка с основными сведениями открывает профиль через UUID, «Играть» — отдельная соседняя кнопка;
в одной строке слева «В игре: …» (время для текущего аккаунта либо гостя, по UUID сборки),
справа «Играть»; вложенных `Button` нет. Статус «Готова» не выводится.
Время и «Играть» показываются только у готовой сборки (`state == .ready`); пока она не готова, карточка
выводит прогресс установки либо название состояния. Карточки одной строки сетки имеют одинаковую высоту
(`maxHeight: .infinity`, выравнивание ячеек по верхнему краю), блок запуска прижат к низу.
Иконка рейла открывает тот же профиль. Установка продолжается при смене страницы.
Остановка, продолжение и повтор установки доступны в профиле.

`InstancePlayControls` показывает «Играть» (вызывающие скрывают его, пока сборка не готова) и поясняет её недоступность: установка не готова,
запуск подготавливается, игра сборки уже работает либо отсутствует действительная Minecraft-сессия.
Microsoft/Xbox-вход сам по себе не разрешает онлайн-запуск. Явный offline-mode использует сохранённый ник,
показанный рядом с кнопкой, и не требует аккаунта. Ошибка показывает сообщение и ссылку на локальный журнал,
когда он существует. Запуск и восстановление процесса описаны в [[Minecraft/Launching]].

## Профиль сборки

`InstanceProfileView` показывает заголовок, состояние установки и разделы «Моды», «Ресурспаки»,
«Настройки», «Миры» (четвёртая вкладка). Всё содержимое страницы — одна колонка шириной до 900 pt (`profileColumnWidth`) с общими
левым и правым краями. Справа в заголовке расположены `InstancePlayControls`, выровненные по правому краю
колонки, правее них — стеклянная кнопка «⋯» высотой с «Играть» (`actionsMenu`, видна всегда), открывающая `NSMenu`: «Дублировать», «Резервная копия» и
«Удалить сборку…». Пункты отключаются по `InstanceStore.managementBlockedReason`, дублирование и копия —
ещё и до готовности сборки. Удаление подтверждается alert-ом о безвозвратном удалении папки с мирами,
модами и Java; затем `onDelete` передаёт удаление `LauncherView`, который сначала с анимацией открывает
список сборок, а после её завершения вызывает `InstanceStore.delete`, чтобы уходящий профиль не читал
удалённую модель. Ошибку удаления показывает alert «Не удалось удалить сборку». Дублирование и копия
показывают под заголовком индикатор операции; копия не открывается автоматически, успешная резервная
копия предлагает «Показать в Finder» ([[Data/Backups]]). UUID выбирает профиль независимо от переименования папки. В заголовке показано «В игре» с тем же
значением и форматтером, что на карточке; «В игре» и «Играть» скрыты, пока сборка не готова. Общее время профиля хранится независимо от сборок
и сохраняется после их удаления ([[Minecraft/Launching]]).

- Моды доступны только для Fabric; профиль Fabric изначально открывает этот раздел, Vanilla — ресурспаки.
  `InstanceFilesView` показывает активные `.jar` и отключённые `.jar.disabled`, иконку из `fabric.mod.json` внутри JAR (либо стандартный значок), переключатель активности справа,
  источник с иконкой (`local`, `modrinth`, `curseForge`), страницу известного источника и меню Finder/удаления.
  Локальный импорт всегда отмечен «Локальный» и не обновляется автоматически. Отключение и удаление
  установленного Fabric API требует предупреждения о зависимых модах.
- Ресурспаки — ZIP/папки в `minecraft/resourcepacks`, для metadata pre-1.6 — `texturepacks`.
  Слева отображается `pack.png` из корня архива/папки либо стандартный значок, справа — переключатель.
  Отключение перемещает пак в соседнюю `.hako-disabled-resourcepacks` (для старых версий — `.hako-disabled-texturepacks`),
  вне каталога обнаружения Minecraft; включение возвращает обратно. Обе папки входят в общий список и
  проверку конфликтов, замена отключённого пака сохраняет отключение.
  Кнопка добавления сохраняет импорт папок; зоны перетаскивания принимают JAR для модов и ZIP для ресурспаков.
  Рядом с заголовком раздела — бейдж «активные/всего» (например, «3/5») в стиле бейджа источника; при пустом списке скрыт.
  Кнопка «Modrinth» (`shippingbox`, как у бейджа источника) стоит в модах между «Проверить обновления» и «Открыть папку»,
  в ресурспаках — левее «Открыть папку», и открывает каталог Modrinth.
  ZIP не распаковывается. Picker и drop отправляют пакет в одну очередь `InstanceContentController`.
  Общий actor `InstanceContent` копирует независимые файлы, запрещает ссылки, проверяет коллизии без учёта
  регистра и подтверждает замену. Для модов активная/отключённая формы имени считаются одним файлом;
  замена отключённого мода сохраняет отключение. Удаление использует системную корзину.
  Контроллер живёт в окружении приложения: очередь и подтверждения не принадлежат текущей вкладке.
  Блокировка `InstanceStore.contentBusy` действует на весь пакет, включая подтверждение, и проверяется
  также запуском, переименованием и повторной установкой. Изменение файлов запрещено при подготовке/работе
  игры; операции модов — при очереди/установке. Возврат приложения и файловые операции обновляют список.
- Настройки — отдельный черновик имени с кнопкой «Сохранить имя»; иконка и параметры сборки сохраняются автоматически.
  Minecraft и выбранный Loader показаны как сведения. Переименование недоступно для очереди/установки
  и во время импорта/удаления, подготовки/работы игры; после остановки `InstanceStore.rename` перемещает папку без загрузки.
  Перед сохранением имени показывается подтверждение, что папка сборки будет переименована.
  При переходе из настроек, со страницы сборки, закрытии окна или завершении приложения незавершённое имя предлагает сохранить переименование
  либо продолжить действие без него. При редактировании работающей игры пояснение указывает, что изменения применятся при следующем запуске.

- Миры — `InstanceWorldsView`: раскрывающиеся карточки с `icon.png` 76 pt (или стандартной иконкой),
  названием, версией сохранения, режимом, датой последней игры и размером всех файлов.
  Заголовок раскрывает установленные датапаки: ZIP и папки, превью `pack.png`, состояние и переключатель.
  Отключение переносит пакет в скрытую папку того же мира; подпись поясняет применение при следующем открытии.
  «Добавить датапак» внутри карточки открывает каталог выбранного мира. Меню «⋯» — копия,
  резервная копия `.hakoworld` и удаление всего мира в корзину через общий sheet подтверждения.
  После резервной копии диалог предлагает показать файл в Finder ([[Data/Backups]]).
  Операции запрещены при работе игры/файлов или неготовой сборке; во время действия есть индикатор.
  «Обновить», появление вкладки, возвращение из каталога, активация окна, снятие `launchBusy`
  после игры и `worldRevisions` после действий перечитывают миры и датапаки раскрытых карточек.
  Отдельно показаны загрузка, пустой список, ошибки с повтором и неизвестные сведения; ошибка NBT
  не скрывает мир. Успешная установка поясняет, что датапак доступен при следующем открытии мира.
  Файловые контракты — [[Minecraft/Worlds]].

## Каталог Modrinth

`InstanceProfileView` хранит `catalog: CatalogDestination?` с `ModrinthInstallTarget` и названием мира и вместо колонки профиля показывает
`ModrinthCatalogView` той же ширины (до 900 pt). Модификаторы профиля остаются на общем контейнере, поэтому
черновик имени, предупреждение о переименовании и выбранный раздел сохраняются. Переход — `.blurReplace`
с `.smooth`, при Reduce Motion — `.opacity`. «Назад к сборке» (⌘[) возвращает к тому же разделу; для датапаков — «Назад к мирам».
Логика API, зависимостей и проверок — [[Minecraft/Modrinth]].

- Заголовок «Моды с Modrinth» / «Ресурспаки с Modrinth» / «Датапаки с Modrinth»; под ним сборка, Minecraft и для модов Loader. У датапаков дополнительно показано имя выбранного мира.
- Поле поиска — стеклянная капсула (`glassEffect`) с обводкой `sakuraDeep` в фокусе; фокус при открытии и по ⌘F,
  Esc и кнопка очищают запрос. Запрос отправляется через 300 мс после набора; сортировка и повтор — сразу.
  Во время обновления результаты приглушаются, в поле — индикатор. Сортировка — стеклянное меню.
- Лента — `LazyVStack` в `instanceSurface`, строки в стиле строк модов: иконка 44 pt (`AsyncImage`, заглушка
  мода/пака), название и описание в две строки. Иконка и название открывают страницу Modrinth в браузере
  (курсор-ссылка, подчёркивание при наведении). Справа «Добавить», «Добавляем…» либо «Установлен».
- При появлении строки `compatibleVersions` даёт новейшую версию каждого канала (`channels`, ошибка не запоминается).
  «Добавить» ставит релиз и серая, если релиза нет; рядом всегда стеклянная кнопка «⋯» той же высоты (`NSMenu` через `ClosureMenuItem`) с «Установить бету X» и
  «Установить альфу Y» — недоступный канал показан серым пунктом. Без релиза под описанием подпись
  «Доступна только бета/альфа», «Доступны только бета и альфа» или «Нет совместимой версии».
- Следующие 20 проектов подгружаются при появлении нижнего индикатора; при новом поиске лента
  прокручивается к началу. Ошибки: `ContentUnavailableView` с «Повторить», «Ничего не найдено».
- «Добавить» недоступна по `disabledReason` (причина выводится над лентой) и во время другой установки.
  «Установлен» вычисляется через `installedProjects` при открытии и после изменения списка файлов;
  индикатор строки держится, пока список установленного не обновится. У датапаков установленное и
  индикатор привязаны к выбранному миру; каталог другого мира показывает блокировку общей файловой
  операции, а не установку в этот мир.

Общий sheet подтверждений в `LauncherView` дополнительно показывает список проектов (иконка 32 pt, название,
пометка; прокрутка выше 260 pt) и необязательную кнопку альтернативы; без основного действия кнопка скрыта.

## Настройки

`SettingsView` использует `LauncherPage`; под заголовком — сегментированный переключатель
«Основные», «Игра», «Хранилище», «О приложении» и прокручиваемое содержимое. Начальный раздел — «Основные».
При смене раздела прокрутка сбрасывается к началу.

«Основные» — карточка «Язык» с `AppLanguagePicker` и пояснением, что меню и системные окна macOS
используют язык системы. Выбор применяется сразу, страница и раздел остаются открытыми ([[UI/Localization]]).

Параметры игры сгруппированы в стеклянные карточки «Java», «Minecraft», «Окно»:
путь к Java, аргументы Java и Minecraft, предел Java heap, полноэкранный режим, ширина и высота окна.
Аргументы, память и путь Java относятся к сборкам с глобальным режимом; окно служит начальным при создании.
`@AppStorage` сохраняет изменения автоматически, без привязки к аккаунту.
Ключи, значения по умолчанию и снимок `GameLaunchDefaults` — в [[Data/Persistence]].

Путь вводится вручную или выбирается через `NSOpenPanel`: один файл, папки выбирать нельзя,
пакеты JDK открываются как папки. Отмена не меняет путь. Сохраняется строка пути;
Java проверяется только при подготовке запуска, security-scoped bookmark не создаётся.
Под полем объясняется, что непустой путь переопределяет Java сборок в глобальном режиме;
в остальных режимах применяется управляемая Java сборки.
Аргументы сохраняются как введённый текст; ползунок памяти переопределяет максимальный heap при подготовке запуска.

Размеры окна — положительные целые числа в пикселях. Поле хранит черновик строки;
неверный ввод помечается сообщением и не заменяет последнее сохранённое значение.
В полноэкранном режиме поля отключены, сохранённые размеры остаются прежними.
Превью использует отдельный `UserDefaults` suite `com.Launcher.Hako.settings.preview`.

«Хранилище» показывает ёмкость, занятый и свободный объём тома с данными приложения:
`FileManager.default.homeDirectoryForCurrentUser` → `URL.resourceValues` с
`volumeNameKey`, `volumeTotalCapacityKey`, `volumeAvailableCapacityKey`.
Данные читаются при открытии раздела и переходе `scenePhase` в `.active`.
Занятое место — разность общей ёмкости и свободного места, полоса заполнения — его доля
в общей ёмкости. Объёмы форматируются по `\.locale` окружения, то есть на языке интерфейса.
Во время чтения — индикатор, при ошибке — «Не удалось получить данные».
Объём сборок — фактически занятые файлы в `~/.hako`, включая резервные копии в `backups/` и `worlds/`, подсчитанные через `InstanceStorage.allocatedSize()`
в `Task.detached`. Пересчёт происходит при открытии, возвращении приложения в активное состояние,
изменении состояния/имени сборок и завершении операций импорта. Общего кеша бинарных файлов игры нет.

«О приложении»: текущая иконка из `NSApplication.shared.applicationIconImage`, название Hako,
описание, версия из `CFBundleShortVersionString`, номер сборки из `CFBundleVersion`, ссылка
на `https://github.com/Liis17/Hako` и та же оговорка о Mojang/Microsoft, что на приветствии.
Отсутствующие значения версии и номера отображаются как `—`; ссылка открывается системным браузером.

## Автоподключение Minecraft

`ContentView` запускает `MinecraftSessionCoordinator.monitor` для текущего аккаунта.
Сервис проверяет срок и обновляет Minecraft-токен через refresh; подробности — [[Auth/MicrosoftAuth]].
Профиль показывает ошибку даже при ранее сохранённом Minecraft-нике и предлагает явный повтор подключения.
Выход очищает сервис сессий, аккаунт и Keychain, сохраняя сборки и процессы игры.

## Обновление Fabric API

«Проверить обновления» есть в модах и ресурспаках; при открытии раздела и по кнопке вызывается
`checkAllUpdates` ([[Minecraft/Modrinth]]). Доступное обновление — оранжевая `arrow.down.circle.fill` слева
от переключателя (подсказка «Обновить до …»), во время обновления — индикатор. Так же выглядит обновление Fabric API.

`InstanceContentController.checkUpdates` проверяет Fabric API. Проверяет только
официальный API с сохранённым происхождением Modrinth; сбой сети не скрывает локальный список.
Новый API проверяется в кэше по хешу и требованиям Loader/Java. Несовместимая версия не предлагается
к установке и не меняет Loader. `update` применяется только по кнопке, сохраняет `.disabled`,
заменяет имя JAR и происхождение без оставления старой версии; ошибки откатывают файловую публикацию.
Локальные файлы, распознанные по хешу как проекты Modrinth, тоже получают обновления; пометка
«Обновляется вручную» скрыта, пока обновление доступно.
