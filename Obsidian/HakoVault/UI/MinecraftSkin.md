# MinecraftSkin

Parent: [[Index]]

## Назначение

Персонаж в полный рост справа на вкладке [[UI/Launcher|профиля]]: прозрачный фон, ходьба
на месте и вращение мышью. При доступном Minecraft — скин пользователя; до загрузки,
без Minecraft и при сетевой ошибке — встроенный классический Стив с обычными руками.
Выбор Стива, ходьбы и управления мышью — решения пользователя.

## Источники и контракты

| Файл | Символ | Роль |
|------|--------|------|
| `macos/Hako/Hako/Minecraft/MinecraftSkin.swift` | `MinecraftSkin`, `MinecraftSkinVariant` | Нормализованная текстура 64×64; варианты `CLASSIC` / `SLIM` |
| `macos/Hako/Hako/Minecraft/MinecraftSkinLoader.swift` | `MinecraftSkinSource`, `MinecraftSkinLoader.load(_:)` | UUID, URL и вариант; асинхронная загрузка и кэш на время работы приложения |
| `macos/Hako/Hako/Minecraft/MinecraftSkinScene.swift` | `MinecraftSkinScene` | Геометрия, материалы, камера, поза и ходьба |
| `macos/Hako/Hako/Views/Launcher/MinecraftSkinView.swift` | `MinecraftSkinView(source:)` | SwiftUI `RealityView`, загрузка, жесты и жизненный цикл |
| `macos/Hako/Hako/Resources/Steve.png` | Резервная текстура | Штатный `wide/steve` из официального клиента Minecraft 1.21.9 |

`MinecraftSkin(data:variant:)` принимает текстуры 64×64 или 64×32; прочие размеры и
нечитаемые данные дают `DecodingError.invalidTexture`. Формат 64×32 всегда классический:
левые конечности восстанавливаются из зеркальных граней правых, новые слои одежды пустые.
Непрозрачный фон в старой области шапки удаляется, если в области одежды нет прозрачности.
Базовые части тела непрозрачны, как в Minecraft; прозрачность внешних слоёв сохраняется.

## Загрузка

`ProfileView` передаёт данные из [[Data/Persistence|Account]]. SwiftUI `.task(id: source)`:

1. Показывает `MinecraftSkin.steve()` из ресурсов приложения.
2. Без UUID оставляет Стива, не отправляя запросов.
3. При известных URL и варианте загружает текстуру напрямую.
4. При недостающих метаданных читает публичный профиль
   `https://sessionserver.mojang.com/session/minecraft/profile/<uuid>` без токенов.
   Base64-свойство `textures` содержит `SKIN.url` и `metadata.model`; `slim` означает узкие руки,
   отсутствие этого признака — обычные. URL и вариант берутся из одного ответа.
5. Ссылки текстур переводятся на HTTPS. HTTP-ответ должен иметь статус 200, текстура —
   поддерживаемый размер. Успешно загруженный скин заменяет Стива; ошибка сохраняет резервный.

`MinecraftSkinLoader.shared` хранит профили по UUID и готовые скины по `MinecraftSkinSource`
в памяти до завершения приложения. Ошибки и отменённые загрузки не кэшируются; профиль
без текстуры кэшируется. `Account` и Keychain загрузчик не меняет. `URLSession` можно передать
в инициализатор для тестов. Уход с экрана или смена источника отменяет задачу;
проверка отмены и ревизии сцены исключает применение позднего результата.

Резервный PNG извлечён из
`https://piston-data.mojang.com/v1/objects/ce92fd8d1b2460c41ceda07ae7b3fe863a80d045/client.jar`,
путь внутри — `assets/minecraft/textures/entity/player/wide/steve.png`.
SHA-256 текстуры: `06628f9cef88520da742ab280a01677ce17c99717f964ed89ed791673121094c`.
Ресурс в бандле обеспечивает резервное отображение без сети и без одобрения Client ID.

## Рендер и управление

RealityKit, без сторонних зависимостей. Шесть частей тела и отдельные оболочки внешних слоёв;
руки шириной 4 пикселя у `classic`, 3 у `slim`. Пиксель модели — 1/16 метра. UV соответствуют
развёртке Minecraft; nearest-фильтрация, без mipmaps. `UnlitMaterial` с умеренным затемнением
боковых граней, прозрачностью и порогом отсечения 0.5 сохраняет пиксели и глубину формы.

Начальный поворот — 30°, наклон — 21°. Перетаскивание на ширину области просмотра даёт
полный оборот; вертикальное движение меняет наклон с ограничением ±45°. Для VoiceOver
есть подпись, подсказка и adjustable action с поворотом на 15°.

`SceneEvents.Update` меняет позу по `deltaTime`, без SwiftUI-обновлений каждого кадра:
цикл 1.5 с, руки ±18°, ноги ±20° в противофазе. `scenePhase != .active` приостанавливает
ходьбу; Reduce Motion отключает её и возвращает спокойную позу. Уход с экрана отменяет
подписку. Камера с углом обзора 38° вписывает фигуру при изменении размера области.
