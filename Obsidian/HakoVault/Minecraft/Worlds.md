# Worlds

Parent: [[Index]]

## Назначение

Локальные миры конкретной сборки и назначение установки датапаков. SwiftData-схема не меняется:
источник сведений — файлы Minecraft. Интерфейс описан в [[UI/Launcher]], каталог — в [[Minecraft/Modrinth]].

## Контракты

- `InstanceWorlds.list(in:)` — actor; принимает корень одной сборки, читает непосредственные папки
  `minecraft/saves` с `level.dat` или `level.dat_old`, включая скрытые папки. Отсутствующие saves дают пустой список без создания файлов.
- `InstanceWorld.id` — имя папки относительно saves, поэтому полное назначение включает UUID сборки.
  Имя мира — `Data/LevelName`, версия — `Data/Version/Name`, режим — `Data/GameType`, последняя игра —
  `Data/LastPlayed` (миллисекунды Unix). Отсутствующие поля остаются неизвестными; имя заменяется именем папки.
- При ошибке основного `level.dat` читается `level.dat_old`; при ошибке обоих мир сохраняется в списке
  с `metadataError`. Чтение и управление датапаками не изменяют метаданные; при копировании меняется только `Data/LevelName` в копии.
- `size` — сумма логических размеров всех обычных файлов мира, включая скрытые файлы, измерения и датапаки.
  В настройках хранилища (`InstanceStorage.usage()`) датапаки мира считаются отдельной категорией и из размера миров вычитаются.
  Ошибка обхода даёт `nil`, а не нулевой размер. `iconData` — `icon.png` до 4 МиБ; недоступная картинка даёт `nil`.
- Порядок — последняя игра по убыванию, затем локализованное сравнение названий; неизвестная дата идёт в конце.
- `datapacksFolder(world:in:)` проверяет путь, существующий мир и обычный файл `level.dat`/`level.dat_old`.
  Символические ссылки запрещены в saves, папке мира, метаданных и datapacks; обход размера ссылки пропускает.
- `InstanceContent.importDatapack` повторяет проверку на файловом акторе и создаёт только саму папку datapacks.
  Исчезнувший мир не создаётся заново. ZIP копируется без распаковки; замена использует прежнюю публикацию
  с временным файлом и откатом. Отключённые датапаки находятся рядом в `.hako-disabled-datapacks`; импорт учитывает их при проверке замены и сохраняет отключённое состояние.
- Локальные ZIP и папки выбираются или перетаскиваются в раскрытую карточку мира; `InstanceContentController.importFiles(_:into:target:)`
  проверяет корневой `pack.mcmeta`, удерживает файловую блокировку и разрешения picker до конца
  пакета, подтверждает замену существующего имени. Другие миры не затрагиваются.
- Происхождение ZIP из Modrinth хранится в `.hako-datapacks.json` внутри мира: проект, версия,
  номер версии, страница, иконка и SHA-512. Хеш проверяется при чтении; отключение сохраняет запись.
  Установка и обновление записывают происхождение; локальная замена его снимает.
  Проверка обновлений распознаёт прежние ZIP по SHA-512 и сохраняет найденные сведения ([[Minecraft/Modrinth]]).

## Управление мирами и датапаками

- `InstanceWorlds.worldFolder(world:in:)` проверяет принадлежность и существование мира без создания родителей.
- `InstanceWorlds.duplicate(_:in:)` делает независимую копию через временную папку рядом с миром.
  Суффиксы ` 2`, ` 3`… подбираются без учёта регистра. Папка и `LevelName` получают один суффикс.
  Все неизвестные NBT-теги сохраняются побайтно; `level.dat_old` тоже получает новое название, если читается.
  Нечитаемые метаданные копируются как есть. Исходный мир не меняется.
- `InstanceWorlds.trash(_:in:)` перемещает весь мир в корзину после повторной проверки пути.
- `InstanceContent.setDatapackEnabled` перемещает ZIP или папку между `datapacks/` и
  `.hako-disabled-datapacks/` внутри этого же мира. Проверяются источник, ссылки и коллизии;
  отсутствующий мир не создаётся заново. `packIconData` читает `pack.png` как у ресурспаков.
- `InstanceContentController.manageWorld` держит общий `contentBusy` до завершения операции и
  подтверждения удаления. `worldBlockedReason` запрещает изменения при запущенной игре,
  файловой операции или неготовой сборке. `worldRevisions` обновляет список после действий;
  работа продолжается независимо от открытой вкладки.
- Проверка и установка обновлений используют `.worldDatapacks(world.id)`; доступные версии,
  состояние проверки и сообщения отделены по UUID сборки и имени папки мира.
  Индивидуальное и массовое обновление сохраняют отключение, проверяют прежний SHA-512
  и повторно проверяют существование мира перед публикацией; `level.dat` не меняется.
- `.hakoworld` и схема манифеста описаны в [[Data/Backups]].

### Windows Core

- `InstanceWorlds.ListAsync(instanceId)` получает папку сборки через `InstanceStore` и выполняет чтение файлов вне UI-потока.
  Отсутствующая `minecraft/saves` даёт пустой список без создания папок. При обеих повреждённых версиях `level.dat`
  мир остаётся в списке с типизированным `WorldMetadataError`; имя берётся из папки.
- `WorldFolder(worldId, instanceRoot)` проверяет отдельный сегмент Windows-пути, существование папки и обычный
  `level.dat` или `level.dat_old`. `DatapacksFolder` дополнительно проверяет путь `datapacks`, но не создаёт его;
  исчезнувший мир не восстанавливается. Действия Core перепроверяют путь под content-lease перед публикацией.
- `DuplicateAsync` и `TrashAsync` работают под общим content lease и разрешены только готовой сборке. Копия собирается
  во временной папке внутри `saves`, затем публикуется перемещением без перезаписи существующего имени. Суффиксы
  папки выбираются с 2 по 999 без учёта регистра. `level.dat` и `level.dat_old` переименовываются только в копии,
  если соответствующий gzip/NBT читается; нечитаемые файлы копируются как есть. Исходная папка не изменяется.
  Отмена удаляет только staging-папку, созданную этой операцией. Удаление использует общий `RecycleBin`; ошибка и
  отказ корзины оставляют мир на месте. Результат копии содержит новый `WorldId` либо типизированную причину отказа.
- Обход размера считает обычные файлы, включая скрытые файлы, измерения и `datapacks`; reparse entries пропускаются,
  а ошибка обхода даёт неизвестный размер. `icon.png` читается только до 4 МиБ. Папки `saves`, мира и назначение
  datapacks не проходят через ссылки/junction; копирование отклоняет reparse point внутри сохранения и перепроверяет
  stage перед публикацией.
- Windows `WorldMetadata` использует .NET `GZipStream` и небольшой big-endian NBT reader без хранения дерева тегов.
  Сжатый и распакованный данные ограничены 16 МиБ, глубина — 64 уровня. Reader проверяет CRC/размер gzip, длины,
  массивы, списки и типы тегов, а строковые поля понимает как UTF-8 или Java modified UTF-8, включая NUL и суррогатные пары.
- Core этапа 7b добавляет локальные и Modrinth-операции датапаков через `InstanceContentTarget.WorldDatapacks(worldId)`.
  Импорт ZIP проверяет ровно один корневой `pack.mcmeta` размером не более 1 МиБ и объект JSON `pack`; ограничены
  число записей ZIP и чтение метаданных. ZIP сохраняется как архив. Папки обходятся без перехода по reparse points.
  При создании операций добавляется только лист `datapacks` в существующий проверенный мир; `saves` и папка мира
  не создаются повторно. Отключённые наборы лежат в `.hako-disabled-datapacks`, происхождение Modrinth — в
  `.hako-datapacks.json` мира. Папка импорта копируется в staging внутри `datapacks` на том же томе; каждый каталог
  staging создаётся нерекурсивно в существующем родителе, поэтому удаление мира или его предков во время копирования
  не восстанавливает их. Отмена и ошибка очищают staging, не меняя исходную папку.
  Проверки, замены, зависимости и обновления выполняются под тем же lease, что запуск,
  установка, копирование и удаление мира. Windows UI для миров и датапаков — следующий этап 7c; архив
  `.hakoworld` реализуется отдельно на этапе 10.

## Чтение NBT

macOS `WorldMetadata` использует системный `zlib`; Windows использует .NET `GZipStream`. Обе реализации имеют
небольшой reader big-endian NBT.
Сохраняются только четыре поля; остальные теги, списки и массивы пропускаются с проверкой границ и длины.
Читаются UTF-8 и Java modified UTF-8 (суррогатные пары). Вход и распакованный поток ограничены 16 МиБ,
вложенность — 64 уровня; отмена проверяется при распаковке и обходе.

## Ограничения

Восстановление и произвольное переименование миров не реализованы. Отдельное удаление датапаков не добавлено;
папки датапаков по хешу не распознаются. UI Windows для списка миров и управления датапаками ещё не подключён.
